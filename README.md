## FAQ

### What exactly is XCutors and what does it include?

XCutors is a curated collection of five popular Roblox executors and script loaders for Windows desktop. It bundles Volt, Synapse Z, Potassium, Wave, and a universal loader called xcutorsLoader that lets you easily switch between them from a single interface.

### How do I update XCutors to the latest version?

When you launch the xcutorsLoader, it automatically checks for new updates and notifies you if a newer version is available. You can also manually download the latest release from the GitHub repository and replace the existing files with the extracted contents.

### Which versions of Roblox are supported by XCutors?

XCutors aims to support the latest stable versions of the Roblox desktop client on Windows. After a Roblox update, there may be a brief period while executor developers release compatibility patches. Check the repository changelog for version-specific support details.

### Can I use multiple executors at the same time?

### Is XCutors compatible with both Windows 10 and Windows 11?

Yes, XCutors is fully compatible with Windows 10 (version 1903 and later) and Windows 11 on 64-bit systems. Make sure your system has the latest .NET Framework and Visual C++ redistributables installed for optimal performance.

### Where can I find Lua scripts to use with XCutors?

You can browse community script repositories, Roblox scripting forums, and the curated script library built into the XCutors interface. Always exercise caution and review any scripts before executing them to ensure they are safe and from trusted sources.

### How do I report a bug or request a new feature?

You can open an issue on the GitHub repository with a detailed description of the bug or feature request, including your Windows version and executor name. Our maintainers typically respond within 48 hours, and community contributions via pull requests are always welcome.

### Why does the injection fail or show an error message?

Injection failures are most commonly caused by outdated executor versions after a Roblox update, missing system dependencies, or anticomponent interference. Try updating to the latest XCutors release, running as administrator, and temporarily adding the folder to your anticomponent exclusion list.
